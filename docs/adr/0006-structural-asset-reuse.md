# 0006 按身体结构复用美术资产与动画

**Status**: accepted

2026-10-19，确认全钓鱼表采用 Meshy 生成、Blender 脚本加工、人工验收的制作路线。42 对普通／极品鱼共享网格、骨架与动画，以配色和少量统一特效区分；不同物种按身体结构建立版本化骨架合同，相近体型复用动作，差异较大时适配或独立制作。关键轮廓和玩法动作优先于复用数量。

没有采用每条记录独立制作，也不让所有生物共用一套骨架：前者放大制作量和运行时资源成本，后者会牺牲虾蟹、飞行生物与特殊首领的关节和攻击表现。骨架层级、静止姿态和动画兼容性在批量制作后修改代价很高，因此先用普通鱼、虾蟹和特殊首领验证，再批量展开。根位移与轨迹由程序驱动，骨骼动画负责局部表现，降低动作复用与技能判定耦合。

范围与待定候选见 [美术资产概要](../art-asset-overview.md)。本文确认复用与职责边界；具体骨架族、数值预算和引擎导入能力仍以试点证据为准。
