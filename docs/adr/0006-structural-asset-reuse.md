# 0006 按身体结构复用美术资产与动画

**Status**: accepted

普通与极品鱼共享网格、骨架与动画，以配色和少量统一特效区分；不同物种按身体结构建立骨架合同，相近体型复用动作，差异较大时适配或独立制作。关键轮廓和玩法动作优先于复用数量。

没有采用每条记录独立制作，也不让所有生物共用一套骨架：前者放大制作量和运行时资源成本，后者会牺牲虾蟹、飞行生物与特殊首领的关节和攻击表现。骨架层级、静止姿态和动画兼容性在批量制作后修改代价很高，因此按结构分族验证后再展开。根位移与轨迹由程序驱动，骨骼动画只负责局部表现，降低动作复用与技能判定耦合。

现存自定义模型与动画分组见 [自定义模型清单与缺口台账](../art-model-inventory.md)；早期生成与加工工作流已归档至 git tag `art-workflow-archive-v1`。制作端的骨架与动作复用不代表引擎能跨网格引用同一动画片段，批量复用前须在编辑器内验证目标网格。
