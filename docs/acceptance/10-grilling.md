# 10. 烧烤

> 本文件是《渔力全开》规格第 10 节的条款清单。格式与必填项见 [TEMPLATE.md](TEMPLATE.md)，小节索引见 [README.md](README.md)。

| ID | 条款 |
| --- | --- |
| 10-01 | 烧烤点从第三区（蟹湖）起设置（A） |
| 10-02 | 玩家在烧烤点 2 米范围内可发起操作（A） |
| 10-03 | 只有未烤制的鱼获可以放入烧烤点（A） |
| 10-04 | 未烤制信物也可以放入烧烤点，放入前提示烤后失去兑换与抽奖资格（A） |
| 10-05 | 烧烤不是配方合成：一次投入只烤制投入的那一份鱼获，不额外生成不同数量或不同种类的食材（A） |
| 10-06 | 烤制倍率在 0 至 2 秒由 1.00 线性升至 1.50（A） |
| 10-07 | 烤制倍率在 2 至 2.5 秒保持 1.50（A） |
| 10-08 | 烤制倍率在 2.5 至 4.5 秒由 1.50 线性降至 0.00（A） |
| 10-09 | 界面以两位小数显示当前烤制倍率（A） |
| 10-10 | 取出时价格与恢复量同乘取出瞬间的倍率，取出后不再随时间变化（A） |
| 10-11 | 4.5 秒仍未取出时鱼获烤糊损毁，从烧烤点消失（A） |
| 10-12 | 烤糊瞬间对烧烤点周围 3 米内的玩家各造成 30 点伤害（A） |
| 10-13 | 烤糊时向操作者提示「烤糊」（A） |
| 10-14 | 取出后物品放回可用格位并保持选中（A） |
| 10-15 | 烤过的鱼不可再次放入烧烤点（A） |
| 10-16 | 烤过的鱼不可用于抽奖（A） |
| 10-17 | 烤过的信物不可用于兑换（A） |
| 10-18 | 烤制计时由服务端自投入时刻开始，客户端计时偏差不影响倍率结算（B） |
| 10-19 | 烧烤点按玩家独立会话：同一设施可被多名玩家同时使用，各会话物品互不干扰（B） |
| 10-20 | 其他玩家不能取走不属于自己会话的物品（B） |
| 10-21 | 玩家退出（离线）时该会话按当时倍率结清并入库存，或原样退回，不复制也不凭空消失（B） |
| 10-22 | 玩家死亡时该会话按与退出相同的路径结算，不产生物品复制或丢失（B） |
| 10-23 | 断线重连后未结清的烧烤会话仍归属原玩家，可继续取出或收回（B） |
| 10-24 | 库存已满时取出被拒绝，烤鱼留在会话中，不丢失也不复制（B） |
| 10-25 | 同一份物品在任一时刻只存在于一个位置（库存、烧烤会话或世界物品），任何恢复路径都不得让两份同时存在（B） |
