## How to get to it (user POV)

1. 从出生点走到 Z1 鱼塘的水边。最近的安全点可以用服务端置位传送，试玩时先确认角色站在岸上、面向水面。
2. 没有新手鱼竿时先去 Z1 钓场商店买一根（新手鱼竿 5 金币），再到本区固定鱼饵刷新点拾取普通鱼饵；刷新点被拾取后 15 秒刷新。
3. 装备鱼竿，选中鱼饵，朝水面抛竿。落点不在可钓水域时画面会提示失败，鱼饵不扣，角色立刻回到可抛竿状态。
4. 有效落水后约 3 秒出结果：没抽到鱼就提示重新抛竿；上钩时出现文字提示、收线按钮呼吸高亮和一次提示音。
5. 点收线按钮把进度从 50% 推到 100%。进度到 100% 播放上岸动作，鱼顶在头上，按钮变成「放下」。
6. 点「放下」后按品级分流：普通与极品鱼逃跑，精英与首领进入战斗并显示逃跑条。

## Gotchas

- 收线进度只有点收线按钮才变化，点进度条无效（4-09）。用自动化连续点击时，先确认点的是按钮区域。
- 打开商店、背包或图鉴不暂停进度（4-10），关闭界面也不触发脱钩。别把「关了面板鱼还在」当成脱钩失败。
- 进度降到 0 是脱钩，但不会自动回到可抛竿：还要再操作一次收竿（4-11）。
- 首领饵优先级高于普通抽取，用后即脱钩，鱼逃跑也不返还（4-17、4-18）。测普通抽取时先把首领饵从背包里拿走。
- 个体倍率范围是 1.00 到 2.00，重量显示两位小数，金币向下取整（4-19～4-22）。别用浮点相等断言价格。
- 4-29～4-31 是 C 级，只能试玩观察；A 级断言的通过不能替代这三条。会话记录里标 `✅` 之前，反推会把它们保持为 `blocked`。
