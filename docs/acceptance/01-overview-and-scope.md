# 1. 概述与范围

> 本文件是《渔力全开》规格第 1 节的条款清单。格式与必填项见 [TEMPLATE.md](TEMPLATE.md)，小节索引见 [README.md](README.md)。

| ID | 条款 |
| --- | --- |
| 1-01 | 工程名固定为《钓鱼怎么这么危险啊喂！》，设计资料名固定为《渔力全开》，两者指同一款游戏，不引入第三种称呼（A） |
| 1-02 | 世界是 SE 状态同步的多人常驻世界，玩家可随时加入与离开，加入不重置世界里已有的状态（A） |
| 1-03 | 同一世界目标同时在线 8 人以上，任何玩家的进入或离开都不打断其他人进行中的流程（B） |
| 1-04 | 8 人以上容量的代码路径由本地连接夹具证明：以 8 名以上虚拟连接连续加入与离开，服务端不丢状态；真实平台容量结论作为生产开关单列，夹具结论不替代它（B） |
| 1-05 | 单人可完成的边界：任何区、任何首领都不要求付费道具、他人救援或稀有抽奖大奖才能通过（A） |
| 1-06 | 成长闭环成立：钓鱼与击杀的产出（鱼、掉落物、金币）能被商店与设施消费，再换回更强的鱼竿与装备推进下一区（A） |
| 1-07 | 玩家状态（血量、饥饿、体型、移速、库存、成长进度）按玩家隔离，只有本人行为能改变（A） |
| 1-08 | 活鱼、地面物品、摆渡、设施属于共享世界，所有玩家看到同一份状态（B） |
| 1-09 | 重复请求、争抢拾取、同时交票、断线重连都不产生重复结算：同一份收益至多入账一次（B） |
| 1-10 | 小队、PK、他人抢救这些延后系统在架构上保留接缝，新系统不复制出一套独立的单人逻辑（A） |
| 1-11 | 平台商店、盲盒、广告/金豆复活、全服纪录在编辑器内只接一层可替换适配层，业务不直接调用平台能力（A） |
| 1-12 | 适配层的失败路径可走通：平台拒绝或超时后给出明确提示，且不扣费、不发放（A） |
| 1-13 | 平台能力在编辑器内经可替换适配层走通成功与失败两条路径；真实平台（商店购买、激励广告回调、金豆复活、全服纪录写入）的验收作为生产开关单列，适配层跑通不作为平台结论（A） |
| 1-14 | 正式美术资源按官方资产表替换显示，占位期间玩法路径照常可跑；资源交付作为生产开关单列，替换只改显示、不改判定参数（A） |

## C 级（试玩取证）

| ID | 条款 |
| --- | --- |
| 1-15 | 占位资源版本下，七个区的鱼与七个首领在场景中都能看到、打到并放下，不出现空模型或穿地（C） |
| 1-16 | 单人玩家以正常金币收入、商店武器与升级，一次连续旅程走完七区、击败全部首领并交付哥斯拉头（C） |
| 1-17 | 七区活鱼以可动模型呈现：静止、移动与攻击三种状态能看出动作差别，不用静态方块代替，碰撞、挂点与抓举不回归（C） |
| 1-18 | 01 鱼塘与战斗空间在场景中连通可行走：从出生点能走到抛竿位与战斗区，不被通道缺口或碰撞卡住（C） |
| 1-19 | 七个钓鱼区的顶部、水下、区间接缝与外围提示物完整：泳到水下不穿地、飞到顶不穿墙、接缝处不掉出世界；三倍体型与礁石岛空战鱼的活动空间不被顶墙截断（C） |
