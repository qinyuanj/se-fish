# 17. 新手任务、剧情与平台边界

> 本文件是《渔力全开》规格第 17 节的条款清单。格式与必填项见 [TEMPLATE.md](TEMPLATE.md)，小节索引见 [README.md](README.md)。

| ID | 条款 |
| --- | --- |
| 17-01 | 新手任务共九步，顺序为：拾取蚯蚓、喂食、购买新手鱼竿、挂饵、首次抛竿、收线上岸、放下鱼获、击杀、捡起鱼获并喂食（A） |
| 17-02 | 第一、二步的蚯蚓数量各为 5 只：先拾取 5 只，再喂食 5 只（A） |
| 17-03 | 新手任务只做引导，不发放原案未定义的任何奖励（A） |
| 17-04 | 新手任务进度写入存档，退出重进后进度不丢失（B） |
| 17-05 | 重复执行已完成的步骤既不让进度回退，也不跳过后续未完成步骤（A） |
| 17-06 | 新档不发放任何调试资源（A） |
| 17-07 | 新手鱼竿售价 5 金币，新档初始金币与 5 只蚯蚓的售价之和都恰好等于该售价（A） |
| 17-08 | 开场以对话界面呈现，不使用占位文本或以聊天日志代替（A） |
| 17-09 | 开场对话支持跳过（A） |
| 17-10 | 已读完或被跳过的对话按已读状态存档，重进后不重复强迫播放（B） |
| 17-11 | 七区 NPC 对话逐一解释当地信物链（A） |
| 17-12 | 七区 NPC 对话说明本区的抽奖与烧烤入口（A） |
| 17-13 | 剧情资源不可用时以可读对话兜底，不出现空白对话或流程中断（A） |
| 17-14 | 正式剧情表现是否完成，不得仅凭资源接口调用成功判定，须另有呈现证据（B） |
| 17-15 | 地图商店使用共享配置里的占位汇率与占位商品 ID 走通兑换；真实参数由平台侧交付后只替换配置，不改判定（B） |
| 17-16 | 广告位使用共享配置里的占位标识走通广告路径；真实广告位由平台侧交付后只替换配置（B） |
| 17-17 | 平台成就使用共享配置里的占位 ID 走通完成与补交路径；真实成就 ID 由平台侧交付后只替换配置（B） |
| 17-18 | 分享任务在平台能力未开放时走明确占位路径，不出现点了没反应的入口；平台开放情况作为生产开关（B） |
| 17-19 | 正式资产 ID 交付前用共享配置里的占位资产 ID 验证玩法；占位只替换显示，不改判定参数（A） |
| 17-20 | 支付、广告与全服纪录在编辑器内只经可替换适配层，真实平台验收作为生产开关单列，不并入玩法条款（B） |
| 17-21 | 编辑器试玩与模拟环境不发放真实付费权益（A） |
| 17-22 | 模拟环境不作为生产环境的后备路径（A） |
