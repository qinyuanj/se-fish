# 8. NPC、兑换与摆渡

> 本文件是《渔力全开》规格第 8 节的条款清单。格式与必填项见 [TEMPLATE.md](TEMPLATE.md)，小节索引见 [README.md](README.md)。

| ID | 条款 |
| --- | --- |
| 8-01 | 每个钓鱼区各有一名钓鱼佬，玩家在 5 米内可与其对话并发起喂食（A） |
| 8-02 | 钓鱼佬按物品表价格回收道具栏中选中且实际可使用的物品，范围含普通鱼饵、多余鱼竿、武器与道具（A） |
| 8-03 | 仍留在背包、未转入道具栏的物品不能被喂给钓鱼佬，喂食不能绕过背包转入规则（A） |
| 8-04 | 未烤制信物喂给钓鱼佬时优先按兑换表兑换成对应产物，而不是按售价回收（A） |
| 8-05 | 已烤制信物喂给钓鱼佬时按烤后价值售卖金币，不参与兑换（A） |
| 8-06 | 兑换表覆盖全部七个钓鱼区，每区各有一条「精英信物换首领饵」与一条「首领信物换车票或成就」（A） |
| 8-07 | 所有兑换比例均为 1 比 1，一件信物换一件产物（A） |
| 8-08 | 兑换前先校验交付后的容量；最终容量不足时拒绝兑换，且不扣除原物品（A） |
| 8-09 | 兑换时允许使用本次交付所释放的格位作为可用容量（A） |
| 8-10 | 火山岛的哥斯拉头兑换为通关成就，而不是船票（A） |
| 8-11 | 去程由一名玩家交一张目的地船票发起，5 秒倒计时后搬运（A） |
| 8-12 | 去程不要求每名乘客持票，搭便船合法（A） |
| 8-13 | 返程按人付金币：付费者立即前往上一个钓鱼区，未付费者留在原地（A） |
| 8-14 | 第 2 至 7 区的返程票价依次为 10、30、90、270、810、2430 金币，即 10 乘 3 的（区号减 2）次方（A） |
| 8-15 | 六条去程与六条返程各有独立标识与独立状态，互不占用对方的倒计时（A） |
| 8-16 | 已到达目的区的玩家再次去程仍需交票，到达不等于免费传送（A） |
| 8-17 | 摆渡过程保留「中途下车（船），概不负责！」的提示文字（A） |
| 8-18 | 击杀掉落与主动丢弃的物品可被任何玩家拾取，没有击杀者保护期（A） |
| 8-19 | 玩家进入掉落物 2 米范围内显示拾取交互（A） |
| 8-20 | 格子全满时拒绝拾取，物品留在原地（A） |
| 8-21 | 每个完整钓鱼区共享 200 件的掉落与丢弃物预算，不按水域小块分别计数（A） |
| 8-22 | 超出预算时按最旧顺序回收物品（A） |
| 8-23 | 回收前对目标物品给出 30 秒闪烁预警（A） |
| 8-24 | 每区设有当地普通鱼饵的固定刷新点，被拾取后 15 秒刷新（A） |
| 8-25 | 首领饵没有固定刷新点（A） |
| 8-26 | 兑换的扣除与发放在同一次服务端结算中完成：不出现扣了信物未给产物、或给了产物未扣信物的中间态（B） |
| 8-27 | 兑换请求重复提交（重复点击、断线重连后重放）只结算一次（B） |
| 8-28 | 同一航线倒计时进行中再次交票被拒绝，且不扣除船票（B） |
| 8-29 | 交票倒计时到期后，载具有效范围内的所有玩家（含搭便船者）一起被搬运，且只搬运一次（B） |
| 8-30 | 到达记录以实际到达为准，搭便船同行者同样记录为已到达（B） |
| 8-31 | 倒计时结束瞬间不在载具范围内的玩家不会被搬运，也不因此损失船票（B） |
| 8-32 | 返程的扣费与传送在同一次结算中完成：金币不足时不传送也不扣费（B） |
| 8-33 | 断线重连后进行中的航线倒计时与玩家所在区与服务端一致，不产生第二次搬运或第二次扣费（B） |
| 8-34 | 掉落物计数与待回收状态有界：回收队列不因长期运行无限增长（B） |

## C 级（试玩取证）

| ID | 条款 |
| --- | --- |
| 8-35 | 摆渡船的停靠位、载具有效范围与落点让玩家能顺利上下船（C） |
| 8-36 | 钓鱼区之间在实机上形成有效阻挡，玩家不能徒步、游泳或借飞行越界（C） |
| 8-37 | 船体可先占位：占位模型不阻挡玩家上下船，也不影响搬运判定（C） |
| 8-38 | 钓鱼佬的 5 米交互提示在场景中与鱼饵刷新点可区分（C） |
| 8-39 | 摆渡的抵达点与出发锚点分离：多名乘客的落点有支撑、有净空且彼此有间距，传送与归属过渡中不被旧区回送（C） |
| 8-40 | 实走六条相邻航线的十二个方向，逐区确认两侧的设施、水域、鱼饵刷新、钓鱼与战斗都能正常进行（C） |
| 8-41 | 步行、游泳、击退与特殊强制移动越界后回到本区有效陆地点，物品、举鱼与玩家状态不丢失，钓鱼区归属不变且不代替摆渡（C） |
