# 3. 持有与操作

> 本文件是《渔力全开》规格第 3 节的条款清单。格式与必填项见 [TEMPLATE.md](TEMPLATE.md)，小节索引见 [README.md](README.md)。

| ID | 条款 |
| --- | --- |
| 3-01 | 界面常驻显示血量与饥饿的当前值与上限，以及图鉴、地图商店、盲盒三个入口（A） |
| 3-02 | 分享任务入口只在平台能力确认后接入，未接入时界面不出现点了没反应的入口（A） |
| 3-03 | 界面常驻显示武器栏、道具栏、鱼饵栏、背包，以及攻击、道具、跳跃、滚动、丢弃五个按钮（A） |
| 3-04 | 装备远程武器时才显示换弹按钮与当前弹量，切回近战装备时两者都不出现（A） |
| 3-05 | 道具栏从 2 格起步，经六次升级到 8 格上限（A） |
| 3-06 | 背包容量按等级依次为 5、10、15、20、25、30、40 格，最后一级补到 40 格（A） |
| 3-07 | 拾取到的物品先填道具栏，道具栏没有空位时才进背包（A） |
| 3-08 | 格内不叠加：同类物品各占一格，一格一件（A） |
| 3-09 | 背包里的物品必须先拖进道具栏才能使用（A） |
| 3-10 | 道具栏与背包之间支持双向移动与同区域内的换位（A） |
| 3-11 | 武器使用独立库存，武器栏同时只装备一件武器（A） |
| 3-12 | 普通鱼饵独立计数，不占道具栏与背包格（A） |
| 3-13 | 首领饵、信物、船票、药水、特殊道具、自救道具各占道具栏或背包的一格（A） |
| 3-14 | 吃饵与钓鱼共用同一份鱼饵库存，任一处消耗都扣同一份计数（A） |
| 3-15 | 首领饵只有放在道具栏才能挂饵，存在背包里时界面可见但提示先转入道具栏（A） |
| 3-16 | 濒死自救是「背包物品必须先转入道具栏」的唯一例外：可从自身库存（含背包）直接查找并使用肾上腺素（A） |
| 3-17 | 选中与手持分离：手中所持不是目标物时，第一次点攻击或道具只切换手持，第二次才真的攻击或用出去（A） |
| 3-18 | 风神之翼选中即装备到背后，哥斯拉选中即变身，都不需要第二次操作确认（A） |
| 3-19 | 丢弃丢出当前选中物的一件，在世界中生成可拾取的物品并保留个体倍率与烤制状态，不是从库存直接删除（A） |
| 3-20 | 丢弃生成的地面物品属于共享世界，其他玩家也能看到并拾取（A） |
| 3-21 | 武器与普通鱼饵也能按件丢弃，丢出的世界物品可被重新拾取回收（A） |
| 3-22 | 库存变更（升级、移动、丢弃、拾取）在断线重连后保持，不丢件也不复制件（B） |
