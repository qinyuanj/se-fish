| 18-15 | 重新连接后弹药消耗与冷却限制继续生效，不能靠重连绕过（B） |
| 18-16 | v1 旧档加载后升级为新版结构，且保留已有财产（B） |
| 18-17 | v1 档升级时，新增字段按明确默认值填充（B） |
| 18-18 | 存档版本非法、版本未知或读取失败时保留原档，不写入空档（B） |
| 18-19 | 进入游戏后的可变操作必须等到存档就绪才执行（B） |
| 18-20 | 离线或重连后，旧会话的异步回调不覆盖新会话的存档（B） |
| 18-21 | 写档成功不得仅以 UpdateAsync 返回快照为准，必须额外校验会话与版本（B） |
| 18-22 | 每次写档都校验会话标识与版本号，不一致时拒绝写入（B） |
| 18-23 | 扣费操作具备可重试的操作身份，重试不重复扣费（B） |
| 18-24 | 发奖操作具备可重试的操作身份，重试不重复发奖（B） |
| 18-25 | 船票与兑换操作具备可重试的操作身份，重试不重复扣费或重复发奖（B） |
| 18-26 | 平台回调缺少唯一凭证时不得声明跨会话幂等已成立，须以平台侧验证结论为准（B） |
| 18-27 | 共享的活鱼与地面物品不进入个人存档（B） |
| 18-28 | 已扣费的抽奖在重进后恢复结算，且不重复发奖（B） |
| 18-29 | 已扣费的兑换在重进后恢复结算，且不重复发奖（B） |
| 18-30 | 烧烤等占用物品的会话必须有明确的退出结算，会话结束时物品归属确定（B） |
| 18-31 | 重进时记录落点不合法，则恢复到同一区的安全点（B） |
| 18-32 | 旧角色对象死亡后再次进入世界，玩家状态绑定到新角色，不继承旧角色的残留状态（B） |
