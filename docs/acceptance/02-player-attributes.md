# 2. 玩家属性

> 本文件是《渔力全开》规格第 2 节的条款清单。格式与必填项见 [TEMPLATE.md](TEMPLATE.md)，小节索引见 [README.md](README.md)。

| ID | 条款 |
| --- | --- |
| 2-01 | 血量上限的基础值为 300（A） |
| 2-02 | 每瓶变大药水让血量上限增加基础值的 20%，即 +60（A） |
| 2-03 | 血量上限封顶 900，变大药水最多生效 10 瓶（A） |
| 2-04 | 体型基础 1 倍，每瓶变大药水 +0.2 倍，上限 3 倍（A） |
| 2-05 | 移动速度按基础值的百分比成长：每瓶加速药水 +10% 基础值（A） |
| 2-06 | 移动速度封顶为基础值的 3 倍，加速药水最多生效 20 瓶（A） |
| 2-07 | 饥饿度上限 300，活动期间每秒下降 1 点（A） |
| 2-08 | 饥饿度为 0 时每秒扣 5 点血量（A） |
| 2-09 | 药水效果永久生效并写入存档，重连或重新进入世界后成长值不变（B） |
| 2-10 | 已到上限时使用药水被拒绝、不消耗，提示已达上限，药水仍留在库存中（A） |
| 2-11 | 到上限后的药水可赠送给其他玩家，赠送后双方库存与成长值同步变化（B） |
| 2-12 | 虚弱在成长后的移速上乘 0.5，乘算发生在药水加成之后（A） |
| 2-13 | 血量与饥饿的恢复量 = 物品表百分比 × 对应属性上限，结果限制在 0 到上限之间（A） |
| 2-14 | 负恢复量不按回血处理，走统一伤害规则（含减伤与濒死锁血判定）（A） |
| 2-15 | 持有核废料桶期间每秒受到 1 点伤害，道具栏与背包中的核废料桶都算持有（A） |
| 2-16 | 核废料桶的持续伤害同样受濒死锁血规则约束，不把人从濒死直接打死（A） |
| 2-17 | 药水加成按基础值的线性累加计算，不按当前值复利叠加（A） |
