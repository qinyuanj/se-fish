# 13. 图鉴与成就

> 本文件是《渔力全开》规格第 13 节的条款清单。格式与必填项见 [TEMPLATE.md](TEMPLATE.md)，小节索引见 [README.md](README.md)。

| ID | 条款 |
| --- | --- |
| 13-01 | 图鉴共 98 条独立记录，其中普通 42、极品 42、精英 7、首领 7（A） |
| 13-02 | 图鉴按七个钓鱼区分页（A） |
| 13-03 | 普通与极品分类展示，精英与首领另有明确的品级入口（A） |
| 13-04 | 成功收线上岸即解锁该鱼种图鉴记录，不等待击杀（A） |
| 13-05 | 同一条鱼的多份掉落不在图鉴重复记为钓取，一次上岸只入账一次（B） |
| 13-06 | 每次上岸更新该鱼种的个人最大钓取重量，仅在超过旧值时刷新（A） |
| 13-07 | 图鉴每条记录含鱼名、品级、钓鱼区、个人最大重量与全服纪录保持者五项（A） |
| 13-08 | 缺少平台纪录时该记录显示未取得数据，不显示虚构纪录（A） |
| 13-09 | 盲盒与信物兑换只解锁对应收集，不参与钓取重量纪录（B） |
| 13-10 | 交付哥斯拉头完成通关成就（A） |
| 13-11 | 全图鉴是额外收集目标，不是通关条件（A） |
| 13-12 | 平台成就后台 ID 交付前，本地先保存通关完成标记，重进后继续补交（B） |
| 13-13 | 重复交付同一成就不得重复授予，已送达标记落账后不再提交（B） |
| 13-14 | 平台查询与提交失败时保留补交，不把失败当成已授予（B） |
| 13-17 | 全服纪录服务未接入时，该列只按未取得数据展示，不展示虚构纪录；真实纪录服务接入作为生产开关单列（B） |
| 13-18 | 平台成就 ID 未交付时保留本地完成标记并支持重复补交；真实平台授予作为生产开关单列（B） |
