# 5. 七区鱼种完整数据

> 本文件是《渔力全开》规格第 5 节的条款清单。格式与必填项见 [TEMPLATE.md](TEMPLATE.md)，小节索引见 [README.md](README.md)。

| ID | 条款 |
| --- | --- |
| 5-01 | 鱼种表恰好 98 条记录，分属七个区（鱼塘、虾池、蟹湖、树林岛、沙滩岛、礁石岛、火山岛），每区 14 条（A） |
| 5-02 | 每条记录含 12 个字段：编号、鱼名、品级、血量、基础攻击、速度、逃跑秒、基础重量 kg、鱼饵、竿级、权重、掉落（A） |
| 5-03 | 品级只取普通、极品、精英、首领四种，每区恰好 6 条普通、6 条极品、1 条精英、1 条首领（A） |
| 5-04 | 同一区内六条普通鱼与对应极品鱼的权重依次为 8、8、8、32、24、16 与 2、2、2、8、6、4，精英权重 10，首领权重 100（A） |
| 5-05 | 逃跑秒一列按品级固定：普通与极品为 1，精英为 180，首领为 300（A） |
| 5-06 | 除精英与首领外，普通与极品的基础攻击一律为 0（A） |
| 5-07 | 鱼饵字段写「任意/无饵」的必定是该区第 1 条普通鱼及其同号极品行，其余行写一种具名鱼饵（A） |
| 5-08 | 竿级字段取 1 到 7 的整数，首领行一律为 1，精英行随区递增为 1、2、3、4、5、6、7（A） |
| 5-09 | 编号在同一区内唯一，极品行与对应普通行同号并以 e 后缀区分（如 1 与 1e）（A） |
| 5-10 | e 后缀只是本文档内的稳定标识，业务侧现有 ID 不需要为对齐这张表而改动（A） |
| 5-11 | 基础重量的单位是 kg，每条记录都取正数（A） |
| 5-12 | 掉落字段按「物品名×数量」成对书写，一条鱼可以有多个掉落物（A） |
| 5-13 | 掉落物名称以本轮裁决统一后的名称为准，不保留旧名（A） |
| 5-14 | 表中未被裁决为错的数值按现状保留、不自行修正，含 4e 行名为极品鲶鱼、极品奶龙 50 千克、极品蛇颈龙 10000 千克与其他行的不一致（A） |
| 5-15 | 表内数值来源是原钓鱼表逐行整理，整理过程不插入新数值（A） |
| 5-16 | 同号极品行与普通行的血量、基础攻击、速度、逃跑秒一致，差异只允许出现在鱼饵、竿级、权重、重量与鱼名（A） |
| 5-17 | 本表不含售价列：鱼获价格由物品基础数据里的基础价乘个体倍率得出，同一数值只在物品表登记一次（A） |
| 5-18 | 精英与首领的逃跑计时取自本表对应行的 180 与 300 秒，与钓鱼流程里的逃跑条倒计时同源（A） |
