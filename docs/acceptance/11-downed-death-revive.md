# 11. 濒死、死亡与复活

> 本文件是《渔力全开》规格第 11 节的条款清单。格式与必填项见 [TEMPLATE.md](TEMPLATE.md)，小节索引见 [README.md](README.md)。
> 他人抢救落点后，濒死锁血、濒死免伤、呼救、其它伤害来源豁免、断线重连结算与血量夹取（11-01、11-03、11-06、11-34～11-36）已由 `tests/native/spec/09_rescue_test.lua` 取证；肾上腺素自救（11-07）等其余条款仍待各自实现。
>
> 广告满血复活一组（11-19、11-21、11-22、11-28～11-32、11-37、11-38）由 `tests/native/spec/11_ad_revive_placeholder_test.lua` 取证：真实广告位属外部交付参数，未交付期间经共享配置的占位广告位走通「濒死 → 死亡 → 广告满血复活」整条路径，复活动作仍只有 `PlayerLife` 的 `FullRevive` 一个落点，占位成功给的是地图内资源（血量、饥饿），不发放平台权益；濒死与死亡两个界面的入口、倒计时暂停与平移、三条复活路径互斥、失败不扣费、重复点击与迟到回调都由该文件断言。金豆入口（11-20）与迟到回调补发（11-33）、占位对称结算（11-39）仍待各自实现。

| 11-34 | 濒死锁血期间其它伤害来源（饥饿、核废料桶持续伤害）不再扣血，解除濒死后不补算这段时间的伤害（B） |
| 11-35 | 濒死或死亡期间断线，重连后不恢复濒死计时，而是按已结算结果回到 10% 血量、虚弱、原地（先做安全落点校验）（B） |

| 11-38 | 观看广告复活经可替换广告适配层走通成功与失败两条路径；真实广告平台回调作为生产开关单列，适配层成功不发放真实付费权益（A） |
| 11-39 | 5 金豆满血复活与肾上腺素购买在占位支付通道下走通扣费与发奖的对称结算，失败时两边都不动；占位通道不发放真实付费权益（A） |
