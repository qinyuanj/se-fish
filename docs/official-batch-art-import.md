选择一个或多个 FBX 模型文件即可导入。可以从不同文件夹分批选择，新导入的模型会追加到列表中。每个模型的贴图请放在对应 FBX 所在的文件夹里。

&nbsp;

## 命名格式总览

| 文件类型 | 格式 |
|---|---|
| 模型文件 | `<basename>[_<上传类型>].fbx` |
| 颜色贴图 | `<basename>_d[_<槽位号>].<ext>` |
| 法线贴图 | `<basename>_n[_<槽位号>].<ext>` |
| 混合贴图 | `<basename>_m[_<槽位号>].<ext>` |
| 四换色贴图 | `<basename>_c[_<槽位号>].<ext>` |

`<basename>` 是模型基础名，`<ext>` 是贴图扩展名。方括号表示可选部分，实际文件名里不用写尖括号或方括号。

&nbsp;

## 模型怎么命名

在模型名末尾加上类型后缀，可以指定上传类型。省略后缀时，编辑器会根据模型是否带骨骼自动判断类型。

| 上传类型 | 文件名示例 |
|---|---|
| 组件 | `rock_unit.fbx` |
| 植被 | `tree_plant.fbx` |
| 蛋仔骨骼角色 | `golem_eggy.fbx` |
| 人类骨骼角色 | `guard_human.fbx` |

&nbsp;

## 贴图怎么命名

去掉 FBX 扩展名和模型类型后缀，剩下的就是贴图要用的模型名。例如，`golem_eggy.fbx` 的贴图以 `golem_` 开头。模型名须完全一致，包括大小写；类型后缀和贴图后缀不区分大小写。

| 贴图类型 | 后缀 | 文件名示例 |
|---|---|---|
| 颜色 | `_d` | `golem_d.png` |
| 法线 | `_n` | `golem_n.png` |
| 混合 | `_m` | `golem_m.png` |
| 四换色 | `_c` | `golem_c.png` |

&nbsp;

## 多个材质槽怎么区分

在贴图后缀后加槽位号，如 `_0`、`_1`。省略槽位号时，贴图归到槽位 0。

```
golem_eggy.fbx    模型
golem_d.png       槽位 0 的颜色贴图
golem_n.png       槽位 0 的法线贴图
golem_d_1.png     槽位 1 的颜色贴图
```

同一槽位使用四换色材质时，用 `_c` 代替 `_d`，法线和混合贴图仍用 `_n`、`_m`。如果同时有 `_d` 和 `_c`，编辑器优先使用 `_d`，按通用材质处理。

同一槽位的同类贴图请只保留一份。例如，`golem_d.png` 和 `golem_d_0.png` 都对应槽位 0 的颜色贴图，同时存在会提示命名冲突。
