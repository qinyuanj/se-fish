# 《渔力全开》策划案内部矛盾与待决题

来源：`design`（策划案正文、钓鱼表、物品表、抽奖表）与 `docs/GameSpec.md` 的逐节对照核对。
去向：每题确认后从本清单删掉，移进[策划案已确认结论](策划案已确认结论.md)；本文件只留还没定的题。题号随删题重排，跨文件引用一律用问题标题，不引用题号。

**数值缺口的口径**：缺的是**数值**时，先在共享配置（`common/GameCfg.lua` 与 `common/cfg/` 的内容表）里放占位值并就地标「未查证」，同时在这里记一笔并写明影响哪条条款；不靠记忆、不写在工单或聊天里。真实数值到位后只替换配置，不改玩法判定（见 [ADR-0029](adr/0029-scope-completeness-and-placeholder-first.md) 第三节）。

## 逐题

### 他人抢救的耗时与打断规则

问：他人抢救濒死玩家要按几秒结算？抢救过程中施救者被攻击是否打断、被打断后进度是否清零？

现状：规格只写「2 米内可抢救」「成功后恢复血量上限 10%」，耗时与打断都没有；共享配置里对应字段暂时标「未查证」。

待定：由策划补一条数值与打断规则；在补上之前，代码只按「一次请求结算一次、恢复 10%」实现，不自行发明耗时。

### 队伍界面的布局

问：队友头像与血量显示在屏幕哪一侧、最多显示几名队友、与自身血量条的距离是多少？

现状：规格只要求「在 HUD 上显示本队队友及每名队友的当前血量」并且「实机分辨率下可读、不与左上角自身血量重叠」，没给布局参数。

待定：由策划给一版布局草图；在补上之前按「右侧竖排、最多 2 名队友（小队上限 3 人）」实现，并在试玩取证时连同 9-23 一并复核。

### 邀请已在队伍中的玩家

问：A 队里的甲邀请已在 B 队的乙，应该拒绝这次邀请，还是让乙接受后自动从 B 队换到 A 队？

现状：规格只写「一支小队最多 3 名玩家」「只有在 2 米内才能邀请」，没有换队语义；换队还牵出「B 队少一人是否解散」的连带判定。

待定：由策划确认换队是否合法。在此之前实现按「拒绝邀请」处理（原因码 `target-in-party`），玩家要换队须先主动离队，
不替玩家隐式解散或离开原队伍。

### 金币页的占位汇率

问：真实商品 ID 与金币兑换汇率交付前，金币页用哪个占位汇率演示购买与到账？

现状：真实汇率与真实商品 ID 属于平台侧交付（原 7-25 的旧口径是「仓库内不自定取值」）。按 ADR-0029 的
占位优先口径，现在在共享配置 `GameCfg.Platform.Placeholder.CoinPage` 里放了明确标「未查证」的占位值：
`CoinPerUnit = 100`（1 元 → 100 金币），两份演示商品 6 元 → 600 金币、30 元 → 3000 金币，商品 ID 用
`placeholder.goods.coin.*` 前缀与真实 ID 区分。占位通道只在地图内到账金币，不发放真实付费权益（#261）。

待定：由策划与商业化确认正式汇率与商品 ID；到位后只替换 `GameCfg.Platform.Placeholder` 这张表并置
`Enabled = false`，玩法判定与结算顺序不动。

### 各招式的起手时长与单人躲避窗口

问：每招的预警起手与躲避窗口各给几秒？哪些招式不需要起手？

现状：规格第 12 节只要求「必须可观察预警」「每个招式都留出可完成的单人躲避窗口」，秒数全部缺失。逐招表 `common/cfg/BossMoves.lua` 按「预警期内离开形状」给了占位值：跺脚 0.8 秒、吐息 1.5 秒、大部分精英招 0.5～1 秒，全部标 `Warning.Unverified = true`；爪击、甩尾这类贴身招不起手，只列「保持在范围外」的躲避窗口。

待定：由策划给一版逐招起手时长；补上之前不改判定，只替换表里带 [未查证] 的字段。

### 哥斯拉跺脚的周期与范围

问：跺脚多少秒一次、作用范围多大、伤害多少？

现状：GameSpec §12 只写「保留正文跺脚及对应范围」，正文不在本仓库（`design` 未挂载），逐招表暂按 2 秒 / 脚边 10 米 / 150 伤害 [未查证]（12-41）。

待定：策划补正文数值；在补上之前，断言只保证「跺脚是独立一招、有圆形预警、伤害与范围与表一致」。

### 虎鲸虎啸与风神翼龙的独立伤害

问：虎啸、投掷、俯冲各自的伤害是多少？

现状：钓鱼表只给通用攻击 35，正文给投掷 100 / 俯冲 260（12-34 要求核对映射、不得静默丢弃），虎啸完全没有数值；逐招表按正文与已有披露值填写并标 [未查证]（12-28、12-34）。

待定：由策划确认三段的伤害；核对前不改配置。
